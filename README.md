# Oil Slick Detection
Oil slick detection in Sentinel-1 SAR imagery using CNNs and geospatial foundation models. The project includes in-distribution versus out-of-distribution evaluation using random and Mediterranean splits, along with explainable AI analysis for model interpretation.

This repository is version one of the project. Further development has been continued in the newer repository at [AhsanShah2019/oilslick-detection.](https://github.com/AhsanShah2019/oilslick-detection/tree/main)
